つまるところ
+ XDPのコードでIPIPトンネルを構築してそのまま次の宛先へ送る(tcpdump不可視)
+ ip -n C0 tunnel a ipip0 remote 192.168.88.20 local 192.168.88.10 dev net0 # ipipパケットがロードバランサーから来たらデカプセリングするよう設定
  ip -n C0 l set ipip0 up # 有効化
  ip -n C0 a add 192.0.2.10/32 dev ipip0 # C0に192.0.2.10を割り当て
  -> 結果ここで解除した後通常のルーティングによりC0(=デカプセルしたホスト自身)のところに向かう
+ 戻りのときは内側のIPアドレス198.51.100.200が宛先として使われるためdirect server returnが実現される
